MCP tools

One tool is missing by design: this deployment is read-only, so the tool that erases a visitor's data is not registered.

Deployment context

What your AI agent reads before answering: the ground rules below tell it how to answer, the site context tells it what the site or business is for, and the history log gives it a recorded cause for a change in the numbers instead of a guess. All three are part of the genug://deployment-context MCP resource.

Read-only: ground rules and the site context cannot be saved, and no history note can be added here. All three files can still be edited directly on the server.

History

    Danger zone

    Reset database

    Permanently deletes every stored event, rejected event and bot-activity row. The event schema itself is untouched. This is meant for clearing out test traffic before going live — it cannot be undone.

    Reset events

    Discards every event file on the volume and copies the image's built-in events back — so events you registered are gone, and edits to the built-ins are undone. Stored data is not deleted: rows collected under a removed event name stay in the database, still counting toward totals while no longer matching any question asked by name. Those are reported afterwards, and in the Schema registry card. It cannot be undone.
